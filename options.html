Personal Torn API

Connect requests Chrome access to api.torn.com if it was restricted. Test connection checks this access and contacts Torn without an API key.

A Minimal key covers travel, inventory, bars and public faction data. Automatic recovery of purchases needs a Full key or custom user/log access to Item abroad buy. With a Minimal key, confirmed purchases observed on your Torn shop page are still tracked. Inventory is cached by Torn for one hour; an inventory change alone does not prove a purchase. Directors need Limited access or company/employees in a custom key to see addiction effects. The key is sent only to api.torn.com in the authorization header. It stays in trusted extension storage on this browser; uncheck Remember to keep it only until Chrome closes. It is never sent to Torn page scripts, YATA, a bot or a server.
